### project-kickoff-skill（项目启动准备）

**什么时候用**：开工前需求还模糊，说不清给谁用、解决什么、放哪、存什么数据时。典型触发：「帮我做个 X」「我要做个工具 / Agent / App / 小程序」「帮我理一下需求」「我该从哪开始」。

**做什么**：先过两道门禁（目标三行、交付载体），再走六个阶段：

1. **理解人** —— 谁用、高频诉求、真问题是什么
2. **画工作流** —— 没有 AI 时真人怎么做
3. **数据** —— 存什么、怎么关联
4. **工程级需求** —— 填需求模板，交给 AI 能直接执行
5. **工具 + 技能 + 壳子** —— AI 怎么动手
6. **第一小步** —— 先跑通一个最小可运行产物

**不做什么**：不写代码、不查资料、不答疑；方案一确定就转给编码类技能。小项目走轻量模式，只做门禁 + 需求 + 第一小步。

**核心原则**：AI 的产出上限 = 需求清晰度。缺失信息问出来、写成文件、逐步确认，不自行编造。

**怎么用**：把 `project-kickoff-skill/` 整个目录放到 WorkBuddy 的 skills 目录下即可。主文件 `SKILL.md` 带 frontmatter（name / description），会被自动识别。

**来源**：搬运自个人 Obsidian 库中的「项目启动准备」技能，正文与文件名均为中文正本。
